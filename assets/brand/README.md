# Assets de marca

Aquesta carpeta reservarà els fitxers oficials de marca quan estiguin confirmats (docs/landing-master-spec.md §16):

- `logo-dark.*` — logotip per a fons clars.
- `logo-light.*` — logotip per a fons foscos (footer).
- `monogram-gs.*` — monograma GS, si es proporciona com a peça separada.

Format preferit: SVG si hi ha originals vectorials disponibles.

## Pendent de confirmació

Vegeu `docs/client-validation-checklist.md`:

- si el logotip oficial ha de dir «Advocat» o «Advocada»;
- si existeixen versions oficials del logo en SVG, PNG o PDF;
- manual de marca o colors corporatius oficials;
- tipografia corporativa, si n'hi ha.

No generar ni aproximar aquests fitxers artificialment mentre no s'hagin confirmat.
