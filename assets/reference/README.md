# Referències visuals

Aquesta carpeta guarda les referències visuals aprovades del projecte.

## Fitxer principal

La captura final aprovada de la landing s'ha de guardar amb aquest nom:

`landing-approved.png`

Ruta completa dins del repositori:

`assets/reference/landing-approved.png`

La imatge que actualment és a la carpeta local `Documentos/gloria-solsona-web` s'ha de moure o copiar aquí abans de començar el desenvolupament.

No utilitzar la captura com una única imatge de pàgina. És una referència per reproduir la landing amb HTML, CSS i assets reals.

La descripció detallada de la composició és a `docs/landing-master-spec.md`.
